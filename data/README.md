# Data

This study uses five waves of the Cyber Security Longitudinal Survey (CSLS).
Due to licensing restrictions, the dataset is not included in this repository.

## How to obtain:

1. Register for or sign in to the UK Data Service.
2. Search for **Cyber Security Longitudinal Survey: Wave 5, 2025 (Study Number 9589) and Cyber Security Longitudinal Survey: Wave 1, 2021 (Study Number 8969)**.
4. Download the `.sav` file in this `data/` folder.
